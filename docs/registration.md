Project Title - "Selective-State Memory for Electricity Demand and Street-View Number Reading"

Project Description - 1. For Task 1, we use the hourly-aggregated ElectricityLoadDiagrams20112014 dataset and predict the `MT_235` electricity-load value two hours ahead from a 168-hour target-history window using a seasonal-residual bidirectional GRU with temporal attention, where the network corrects a timestamp-aligned 24-hour seasonal forecast. We additionally evaluate a Mamba-2–GRU hybrid on the same residual base, alongside persistence, seasonal, corrected ridge, attention-free recurrent, and matched selective-state ablations.

2. For Task 2, using the same ElectricityLoadDiagrams20112014 dataset and `MT_235` target, we use a seasonal-residual 168-hour LSTM encoder and autoregressive LSTM decoder with Bahdanau attention to forecast the next five consecutive hourly load values. We additionally evaluate a Mamba-2 encoder with the same attentive LSTM decoder, comparing both methods with timestamp-aligned seasonal baselines, corrected direct ridge regression, a recurrent model without attention, and matched static-state ablations.

3. For Task 3, we use the full-number format of the Street View House Numbers (SVHN) dataset, merge train and extra, and follow the common 1.3x ground-truth union-box crop, 64x64 resize, random 54x54 training crop, and center evaluation crop protocol. Each cropped image is paired with an ordered digit sequence. We build a CNN encoder with a visual-attention GRU decoder and length head, then test a bidirectional Vision-Mamba visual token mixer before the GRU decoder, comparing it with a no-attention GRU, a public-practice multi-head CNN, a CRNN-CTC baseline, and selective-state ablations.

Link to Download Data - Task 1 & 2: ElectricityLoadDiagrams20112014 (https://archive.ics.uci.edu/dataset/321/electricityloaddiagrams20112014) and Task 3: Street View House Numbers (SVHN), Format 1 Full Numbers (https://ufldl.stanford.edu/housenumbers/)
